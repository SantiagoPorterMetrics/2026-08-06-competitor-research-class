## How this section works
- The file you edit is `<that folder>/index.html`. It's a **standalone, previewable deck** — open it in a browser to see just this section.
- Each slide is a `<section class="slide pad" data-layout="...">…</section>` block inside `<div class="stage">`.
- The first slide is already a title/divider — keep it, replace the TODO placeholder slide with real content.
- Reference shared logos as `../_shared/logos/…`.
- The head links `../_shared/styles.css` and the body loads `../_shared/slides.js` — leave those paths as-is.

## Rules (important — parallel chats are editing other folders at the same time)
1. **Only edit files inside my section folder.** Never touch other `NN-*` folders.
2. **Don't edit `_shared/`** unless I explicitly ask — other chats depend on it.

4. Keep every slide previewable and on-brand. When in doubt about a layout, copy a pattern from the reference deck rather than inventing one.
